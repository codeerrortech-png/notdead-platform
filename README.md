# NOTDEAD – Cybersecurity Training Platform

A modern, futuristic cybersecurity platform built with React, Vite, TailwindCSS, Framer Motion, and React Router.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Features

- **Home** – Hero, terminal typing animation, cyber grid
- **Courses** – Course cards with level, duration, rating
- **Membership** – Monthly/yearly pricing plans
- **Tools** – Marketplace grid by category
- **Services** – Breach intelligence service cards
- **Resources** – Blog, OSINT guides, tutorials, case studies
- **Community** – Forums, groups, challenges, leaderboard
- **Testimonials** – Animated testimonial cards
- **Login / Signup** – Terminal-style auth UI
- **Dashboard** – Sidebar, progress, tools, certificates, notifications
- **Footer** – Links, newsletter, social
- Loading screen, neon buttons, glassmorphism, responsive layout

## Tech

- React 18 + Vite
- TailwindCSS (custom cyber theme)
- Framer Motion
- React Router 6
- Lucide React
